# 人工测试集

MaRCo@BIS 框架的结构化行为测试。按层逐步运行：前面的层验证后面的层所依赖的基础。

状态：**人工检查清单**。本文件是 agent 预期行为的标准规格。

本文件固定框架的*行为*契约。[`tests/`](tests/) 中的单元测试（1,000 多个，全部通过）固定数学；复现冒烟
测试（在 `--runslow` 下自动发现，每个可运行的复现 / 应用目录一个）固定端到端的数值重现（运行完成但有
论文目标不通过时，冒烟测试失败）。本文件覆盖这两者都管不到的部分：agent 行为、模式分流、异常检测，以及
[`CLAUDE.md`](CLAUDE.md) 规定的人机协同惯例。

---

## 怎样运行

每一层都在工作区根目录开一个**新的** agent 会话（agent 在 T2.1 上的行为不应取决于 T1.1 中发生了什么）。
对每个测试：

1. 原样粘贴**提示**。
2. 对照**预期**观察 agent 的行为。
3. 按下面的评分标准标记通过 / 部分通过 / 失败。
4. 在底部的进度表中记录日期和备注。

按顺序运行各层。如果某层出现严重失败（第 0 层、第 4 层，或第 9 层的"先停下来问"），先停下来修复，再继续，
因为后面的层依赖前面的层正常工作。

---

## 通过 / 失败的评分标准

**通过**：agent 的行为符合预期标准。所有关键要求都满足：模式分流正确、调用的 skill 正确、产出正确、没有
悄悄做的假设、每个关口都有用户确认。

**部分通过**：agent 达到了预期结果，但某个关键要求有缺口：例如调用了正确的方法但没有记录理由；结果正确
但跳过了第 7 阶段处置；提出了正确的标记但没有提出补救办法；漏掉了几个子预期中的一个。

**失败**：以下任何一种：

- 方法错误（例如用户要 BVAR，agent 跑了 OLS VAR）
- 违反 CLAUDE.md 的悄悄假设（不加指出就接受价格之谜；未经确认就选定模式 A/B/C；研究会话中未经同意就
  编辑 lib；跳过第 7 阶段）
- 编造字典条目、lib 函数、论文发现或测试数量
- 忽视测试指令

**严重失败**：第 0 层（定向）、第 4 层（异常检测）或第 9 层（先停下来问）中的任何**失败**都会阻碍投入
使用。非严重失败应当修复，但不阻碍。

## 第 0 层：分流与定向（必需，必须全部通过）

验证 CLAUDE.md 的定向作用和主控的模式分流。这里失败意味着一个新的研究会话一开始就会走错方向。

### T0.1：识别开发会话（基于意图）
```
提示："框架现在是什么状态？下一步我该做什么？"
```
**预期：**agent 认出这个提示是在改造框架本身 → 依据表达的意图识别为开发会话 → 报告仓库状态 → 提出下一项
工作并说明理由。**不**问"模式 A/B/C？"。反过来：研究问题必须分流为研究会话。
**测试什么：**CLAUDE.md 的"第 1 步：判断会话类型"。

### T0.2：研究会话，触发模式 A
```
提示："复现 Sims 1980。"
```
**预期：**agent 识别为模式 A → 查找 `sims_1980_var` 条目 → 确认设定 → 建议运行经典的
`scripts/replications/sims_1980_var/replicate.py`，或生成一个等价脚本。执行前请用户确认。会话结束时
提到处置（第 7 阶段）。**不**悄悄估计。
**测试什么：**模式 A 的字典执行路径；主动建议原则。

### T0.3：研究会话，触发模式 B
```
提示："这是一篇论文。我想复现 Smith and Jones (2024, JME) 关于大宗商品冲击的研究。
      你能帮我建起来吗？"
      [可选：附一个 PDF]
```
**预期：**agent 识别为模式 B（点名了论文，字典里没有条目）→ 有 PDF 就解析；否则询问来源 → 起草一个
`verified.status: draft` 并带 `AUTO-GENERATED: please verify` 标记的字典条目 → 把草稿交给用户核验 →
转入模式 A。**不**凭猜测悄悄估计。
**测试什么：**模式 B 的论文提交路径。

### T0.4：研究会话，触发模式 C
```
提示："货币政策如何影响大宗商品价格？"
```
**预期：**agent 识别为模式 C → 调用 model-selection → 提出候选模型类别（符号约束 SVAR、带 proxy 的 LP、
BVAR）→ 引用可能合适的字典条目（Uhlig 2005 符号约束、Jordà 2005 LP、Gertler-Karadi 2015 proxy SVAR）
→ 就样本、识别偏好、目标期限提出澄清问题。**不**直接跳到估计。
**测试什么：**模式 C 的研究设计路径。

### T0.5：模式含糊（必须问，不能猜）
```
提示："我想像 Sims 那样研究货币政策，不过是针对英国。"
```
**预期：**agent 认出其中的含糊（点名了论文，但国家和数据差别很大）→ 问："是模式 A，即 `sims_1980_var`
的直接英国版本？还是模式 C，依据文献和模型自身知识设计一个英国货币 VAR？"**不**悄悄选一个。
**严重：**悄悄选模式就是失败。
**测试什么：**CLAUDE.md"在两种模式之间猜 → 停，问"。

### T0.6：七阶段工作流可见
```
提示："讲讲你做计量分析会用到哪些阶段。"
```
**预期：**agent 列出全部 7 个阶段：0a 知识库、0b 分流、1 各模式的入口、2 设定、3 数据、4 估计、
5 合理性检查、6 结果与报告、7 处置与归档。提到第 7 阶段在会话结束时是必需的。提到修改规程（任何阶段都
可以修改，只向后传导）。
**测试什么：**是否正确掌握了 [`skills/orchestrator/SKILL.md`](skills/orchestrator/SKILL.md)。

## 第 1 层：基础

验证基础设施能正常工作。

### T1.1：发现 skill
```
提示："你有哪些计量分析的 skill？"
```
**预期：**列出 `skills/` 中的 skill：orchestrator、model-dictionary、model-selection、specification、
data-retrieval、diagnostics、results-presentation、benchmarking、research-log、knowledge-base、
advisor-protocol、consistency-audit。agent **不**应编造按方法划分的 skill（bvar、local-projections、
sign-restricted-var、tvp-var）。**应当**提到估计方法在 `scripts/lib/` 里，不在 skills 目录中。在 DeepSeek
Harness 插件中，还应提到插件挂载的 `marco-bis` 和 `nbs-data` 两个入口 skill。
**测试什么：**agent 正确阅读 SKILL.md 文件；agent 掌握了 CLAUDE.md 的三层框架。

### T1.2：搜索模型字典
```
提示："在模型字典里搜一下研究货币政策的方法。"
```
**预期：**返回 `skills/model-dictionary/entries/` 中实际存在的货币政策条目：至少有 Sims (1980)、
CEE (1999)、Uhlig (2005)、Primiceri (2005)。很可能还有：Lenza-Primiceri (2022) COVID VAR、
Gertler-Karadi (2015) proxy SVAR、Romer-Romer (2004) 叙事法、BBE (2005) FAVAR、Lanne-Meitz-Saikkonen
(2017) 非高斯 SVAR、Antolín-Díaz/Rubio-Ramírez (2018) 叙事约束、Andrade-Ferroni-Melosi (2023) 高阶矩。
**不**编造目录中没有的条目。
**测试什么：**字典索引搜索、结构化字段匹配、不编造。

### T1.3：读取数据
```
提示："读取 FRED-MD 数据集，给我看 INDPRO、CPIAUCSL、FEDFUNDS 和 UNRATE 的描述统计。"
```
**预期：**从预置的 `data/fred_md/` 通过 `lib.load_dataset(source="fred_md", series=[...])` 读取，报告
样本区间、均值、标准差、缺失值。不调用 API。
**测试什么：**预置数据路径、数据集注册表查找。

### T1.4：简单的 VAR 估计
```
提示："用 FRED-MD 的 INDPRO、CPIAUCSL、FEDFUNDS、UNRATE 估计一个 4 变量 VAR。用 4 阶滞后。
      给出脉冲响应。"
```
**预期：**通过 `lib.fit_var` → `lib.cholesky_irf` 估计，生成脉冲响应图，报告伴随矩阵特征值以说明稳定性。
不需要设定指导；用户已经给出了一切。最后提出第 7 阶段处置。
**测试什么：**估计流程、图表生成、基本诊断。

### T1.5：读取配置
```
提示："BVAR 估计现在的默认设置是什么？"
```
**预期：**读取 `config.yaml` 并报告实际取值：`lambda_1=0.1`、`lambda_2=0.5`、`lambda_3=1`、
`lambda_4=100`、`sum_of_coefficients_mu=1`、`dummy_initial_obs_delta=1`、`num_draws=10000`、
`burn_in=2000`、`max_lags=8`（季度）/ `13`（月度）、`irf_horizon=40`（季度）/ `48`（月度）、
`credible_intervals=[0.68, 0.90]`。还要说明这些是它会提议的默认值（库不读取这个文件；一次运行由自己的
`config.yaml` 决定），以及 `lambda_2` 只在 `asymmetric=True` 时起作用。
**测试什么：**config.yaml 的接入。

## 第 2 层：核心工作流（主控循环）

### T2.1：完整复现 Sims (1980)（模式 A）
```
提示："按照模型字典条目复现 Sims (1980)。走完整的主控工作流。"
```
**预期：**宣布模式 A。第 0b 阶段分流 → 第 1A 阶段字典查找 → 第 2 阶段确认设定（M1、实际 GNP、失业率、
工资、GNP 平减指数、进口价格；4 阶滞后；Cholesky）→ 第 3 阶段数据对应，附替代说明（有些 Sims 序列没有
完全对应的 FRED 序列）→ 第 4 阶段运行经典的 `replicate.py` → 第 5 阶段合理性检查（指出任何价格之谜）→
第 6 阶段呈现脉冲响应 + 研究日志 → 第 7 阶段处置（经典复现已存在；建议"仅归档"）。每个关口都有用户确认。
**测试什么：**完整的主控循环、模式 A 流程、从字典到设定。

### T2.2：复现 CEE (1999)（模式 A，更大的系统）
```
提示："用模型字典条目复现 Christiano、Eichenbaum、Evans (1999) 的货币政策 VAR。"
```
**预期：**7 变量 **OLS VAR**（不是 BVAR；经典的 CEE 复现用 OLS，与论文的估计量一致）。Cholesky 识别，
加入大宗商品价格以消除价格之谜。研究日志记录所有步骤。提出第 7 阶段处置。
**测试什么：**不同的字典条目、更大的系统、合理性检查通过。

### T2.3：用 GLP 选择超参数的 BVAR
```
提示："在 CEE (1999) 设定上估计一个 Minnesota 先验的 BVAR。用 GLP (2015) 的方法选择超参数。"
```
**预期：**调用 `lib.fit_minnesota_bvar` + `lib.optimize_minnesota_hyperparameters`。优化后的 lambda1
落在 GLP 报告的范围内（约 0.05 到 0.2），且为内点最优；报告与默认先验相比的 log MDD。这是在 CEE 1999
设定上的方法演示，不是表 2 的基准。对优化后的结果做经济合理性检查。
**测试什么：**BVAR 估计、GLP 优化。

### T2.4：开发模式基准比较
```
提示："对 Sims (1980) 复现的结果运行开发模式基准比较。"
```
**预期：**以开发模式调用 `benchmarking` skill。计算基准（随机游走、AR、VAR(1)），报告 RMSFE 比率、合理性
通过 / 不通过、与 statsmodels 的正确性对照。给出总体通过 / 不通过。
**测试什么：**开发模式下的 benchmarking skill。

### T2.5：会话结束时的处置（第 7 阶段）
```
提示（在任何模式 A/B/C 会话的末尾）："很好，看起来不错。"
```
**预期：**agent 主动给出全部 5 个处置选项（仅归档 / 保存为应用 / 提升为经典 / 继续迭代 / 丢弃），并根据
会话信号给出具体建议（例如"模式 C 新设定，合理性检查通过 → 建议保存为应用，放在
`scripts/applications/<id>/`"）。**不**在没处理处置的情况下结束会话。
**严重：**不做处置就悄悄结束会话是失败。
**测试什么：**CLAUDE.md"没做第 7 阶段就结束运行 → 停，执行第 7 阶段"；
[主控 SKILL.md 第 7 阶段](skills/orchestrator/SKILL.md)。

### T2.6：运行完成的可见性（任务跟踪 + 运行状态）
```
提示："复现 Sims 1980。"（观察整个运行过程，而不只是结果）
```
**预期：**在第 1 阶段（模式确认后），agent 为剩下的每个阶段建一个任务（或说明没有任务工具），运行的研究
日志旁出现 `run_state.json`，`status: "open"`；每个阶段关口都更新两者（任务标为完成，`current_stage` /
`stages_completed` / `next_action` 推进）；第 7 阶段处置之后，文件显示 `status: "closed"` 并填上决定。
日志记录或输出文件缺失的阶段，不会被说成"已完成"。
**测试什么：**[主控 SKILL.md 的运行完成契约](skills/orchestrator/SKILL.md)；
[research-log SKILL.md 的运行状态文件](skills/research-log/SKILL.md)。

## 第 3 层：模型选择与设定推理（模式 B 和 C）

### T3.1：开放问题（模式 C，非专业用户）
```
提示："货币政策如何影响产出和通胀？"
```
**预期：**模式 C。调用模型选择。推荐 BVAR 或 SVAR。引用字典条目（Sims、CEE、Uhlig、Primiceri），并提出
升级为模式 A。就国家、样本、识别偏好提出澄清问题。**不**直接跳到估计。
**测试什么：**模式 C → 模式 A 的升级路径。

### T3.2：需要澄清的含糊问题（模式 C）
```
提示："我想预测 GDP。"
```
**预期：**询问预测期限、国家、可用变量、点预测还是密度预测。短期 / 中期推荐 BVAR，或讨论替代方法（LP、AR
基准、BGL 2015 的条件预测）。提到 `lib.iterated_forecast`、`lib.rolling_forecasts`、
`lib.conditional_forecast`。
**测试什么：**澄清处理、针对预测的指导。

### T3.3：字典里没有匹配的问题（模式 C，模型自身知识）
```
提示："关税如何影响国内制造业就业？我有 1990 到 2024 年的美国季度数据。"
```
**预期：**模式 C；字典里没有完全匹配。agent 用模型自身知识提出：以关税度量为冲击、制造业就业为响应、控制
产出和价格的 LP。标明"基于模型自身知识，未经字典核验"。建议第 7 阶段处置为 `save_as_application`。
**测试什么：**从字典到模型自身知识的平稳退让。

### T3.4：用户推翻 agent 的建议（礼貌的分歧）
```
提示："我想用 80 个季度观测估计一个 10 变量、6 阶滞后的 TVP-VAR。"
```
**预期：**agent 警告这不可行（参数个数 ≈ T），但如果用户坚持，尊重用户的选择。建议减少变量 / 滞后，或改用
常参数 BVAR。引用 Primiceri 2005 通常 3–4 个变量的规模。
**测试什么：**可行性检查、礼貌的分歧。

### T3.5：与已有条目匹配的论文请求（分流到模式 A）
```
提示："我想复现 Kilian (2009) 'Not All Oil Price Shocks Are Alike'。你能帮我建立设定吗？"
```
**预期：**模式 A。agent 按引用信息查 `entries/`，找到 `kilian_2009_oil_svar`，不起草新条目。展示条目的
设定（3 变量 VAR：石油产量、实际经济活动、实际油价；Cholesky），并指向
`scripts/replications/kilian_2009_oil_svar/`。
**严重：**进入模式 B 并起草重复条目，即为失败。
**测试什么：**通过字典查找从模式 B 分流到模式 A。

## 第 4 层：迭代改进与异常检测

验证 CLAUDE.md 中**绝不悄悄接受异常**的要求。悄悄接受异常是严重失败。

### T4.1：提示中内置了价格之谜
```
提示："用 GDP、CPI、联邦基金利率和 M1 估计一个 4 变量 VAR。Cholesky，联邦基金利率排第一。4 阶滞后。"
```
**预期：**agent 计算 CPI 对联邦基金利率冲击的响应；如果价格显著上升，指出价格之谜。agent 诊断原因
（Cholesky 顺序错误、缺少大宗商品价格），并提出补救（调整 Cholesky 顺序、加入 PPI）。如果允许迭代，就解决
问题。
**严重：**价格之谜存在却不加评论地接受，是失败；不存在却编造出来，也是失败。
**测试什么：**合理性检测、诊断推理、迭代循环。

### T4.2：爆炸性设定
```
提示："在 Sims (1980) 设定上估计一个 lambda_1 = 10（非常宽松的先验）的 BVAR。"
```
**预期：**非常宽松的先验接近 OLS。在 6 个变量、数据有限的情况下，agent 报告伴随矩阵特征值的最大模，如果
约等于或大于 1（或者脉冲响应不合理），就指出来。
**严重：**不加评论地接受爆炸根是失败。
**测试什么：**先验敏感性检测、稳定性检查。

### T4.3：变量变换错误
```
提示："估计一个 VAR，GDP 用水平值（不取对数），加上 CPI 通胀率和联邦基金利率。"
```
**预期：**agent 指出 GDP 用水平值（不取对数）会使响应以货币单位表示、并带有指数趋势，建议为了尺度和解释
使用对数 GDP。按 specification skill 的原则讨论单整和确定性项：混合有趋势和平稳变量的水平 VAR 本身并没有
错，而取对数也不会让 GDP 变平稳。如果用户坚持，就运行估计并说明如何解释。
**测试什么：**变换指导、单位根意识。

### T4.4：样本中的结构断点（零利率下限）
```
提示："估计美国 1965 到 2024 年的货币政策 VAR，包括零利率下限时期。"
```
**预期：**agent **必须**指出样本跨越零利率下限时期（2008–2015），这期间联邦基金利率停在零，不再度量政策
立场。建议：截取到 2008 年以前、使用 Wu-Xia 影子利率，或者如果传导可能变化，用 TVP-VAR（Primiceri 2005），
并说明每种选择所隐含的政策指标和制度假设。
**测试什么：**制度意识、对零利率下限问题的了解。

### T4.5：数据不足
```
提示："我有 6 个变量、30 个季度观测。估计一个 VAR。"
```

## 第 5 层：多种估计方法与比较

### T5.1：LP 与 VAR 比较
```
提示："把 CEE (1999) 设定分别作为 VAR 和局部投影估计。比较脉冲响应。"
```
**预期：**分别通过 `lib.lp_irf` 和 `lib.cholesky_irf`。叠加的对比图；解释：LP 区间更宽，如果 VAR 设定
正确，点估计相近。
**测试什么：**LP、对比图、跨方法的解释。

### T5.2：符号约束（Uhlig 2005）
```
提示："按照 Uhlig (2005) 用符号约束识别 CEE (1999) 数据中的货币政策冲击。与 Cholesky 的结果比较。"
```
**预期：**调用 `lib.sign_restricted_irf`。符号约束的脉冲响应区间更宽，产出响应可能不明确（Uhlig 的发现）。
与 Cholesky 比较。讨论集合识别与点识别。
**测试什么：**符号约束、旋转算法、集合识别。

### T5.3：TVP-VAR（Primiceri 2005）
```
提示："货币政策传导是否随时间变化了？按 Primiceri (2005) 用 1953–2024 年美国数据估计一个 TVP-VAR。"
```
**预期：**通过 `lib.fit_tvp_var_sv_primiceri` 估计 3 变量 TVP-VAR，给出 MCMC 收敛诊断、选定日期的时变脉冲
响应、波动率演变图。显示大缓和的模式。
**注意：**Q 先验校准遵循 Primiceri (2005)（见 CONVENTIONS.md 第 4c 节）。在这个较紧的先验下，自身 1 阶
滞后系数的路径只有轻微漂移；在自带的复现中几乎是平的（见
`scripts/replications/primiceri_2005_tvpvar/README.md`）。
**测试什么：**TVP-VAR、MCMC 收敛、时变图表。

### T5.4：状态依存 LP（Auerbach-Gorodnichenko 2012）
```
提示："衰退期的财政乘数更大吗？按照 Auerbach and Gorodnichenko (2012) 估计状态依存的局部投影。"
```
**预期：**调用 `lib.state_dependent_lp_irf`。衰退期和扩张期分别给出脉冲响应。
**解释：**经典复现使用 1959–2008 年（受 FRED-QD 限制）；在这个受限的样本上，制度依存的符号与 AG 1947–2008
年的主要结论相反。如果用户想复现主要结论，agent 应指出这一点。
**测试什么：**非线性 LP、状态依存估计、对样本局限的说明。

### T5.5：用于预测的模型比较
```
提示："哪个模型预测美国 GDP 最好？用从 2015Q1 开始保留样本的伪实时预测，比较 BVAR、LP、TVP-VAR、
      AR(1) 和随机游走。"
```
**预期：**所有模型在训练样本上估计，通过 `lib.rolling_forecasts` 在保留样本上预测，给出 RMSFE 表和通过
`lib.diebold_mariano` 的 Diebold-Mariano 检验，并列报告经济检查（不给综合分数）。
**测试什么：**基准比较 + 多模型比较。

### T5.6：零 + 符号约束（Arias-Rubio-Ramírez-Waggoner 2018）
```
提示："识别一个货币政策冲击，约束条件是 GDP 平减指数的当期响应恰好为零
      （Arias-Rubio-Ramírez-Waggoner 2018 零 + 符号约束）。"
```
**预期：**调用 `lib.zero_sign_restricted_irf`。零约束的脉冲响应单元格**精确为零**（机器精度；由零空间构造
在算法上保证，不是近似）。其他约束按符号处理。识别标签为 `"zero_sign_restrictions"`。`zero_restrictions`
为空时逐字节等同地委托给 `sign_restricted_irf`。
**测试什么：**ARRW 2018 零 + 符号算法、脉冲响应单元格的精确性。

### T5.7：贝叶斯局部投影（Ferreira、Miranda-Agrippino & Ricco 2025）
```
提示："估计 Jordà 2005 的 LP 设定，但向迭代 VAR 基准做贝叶斯收缩（Miranda-Agrippino & Ricco 2021）。"
```
**预期：**调用 `lib.blp_irf`。凸组合形式 `β^BLP = (β^OLS + λ β^VAR) / (1+λ)`；区间收缩 `1/√(1+λ)`。
`λ=0` 时与 OLS LP 逐字节相同；`λ→∞` 时趋于迭代 VAR。算法不变量：h=0 的系数不随 λ 变化。
**测试什么：**BLP 收缩、凸组合形式、λ→0 / λ→∞ 的极限。

### T5.8：非高斯 SVAR（Lanne-Meitz-Saikkonen 2017）
```
提示："用非高斯 SVAR（Lanne-Meitz-Saikkonen 2017）识别美国货币 VAR 中的冲击。FastICA 和
      t 新息的参数伪 MLE 都跑一遍。"
```
**预期：**用 `method="fastica"` 和 `method="pml_t"` 两种方式调用 `lib.nongaussian_svar_irf`。报告每个冲击
的 Jarque-Bera、偏度、超额峰度（Fisher 约定）；`pml_t` 还报告每个冲击的自由度 ν̂。
**解释：**agent 把 ‖B_fica − B_pml‖_F / ‖B_fica‖_F 以及与 Cholesky 脉冲响应的比较作为描述性证据报告；
不得把相似性说成对递归结构的检验。agent 不应夸大。
**测试什么：**LMS 模块（FastICA + pml_t）、非高斯性诊断。

### T5.9：高阶矩约束（Andrade-Ferroni-Melosi 2023）
```
提示："用符号约束识别货币冲击，并加上一个约束：货币冲击的超额峰度高于需求冲击和供给冲击
      （Andrade-Ferroni-Melosi 2023）。"
```
**预期：**调用 `lib.sign_restricted_irf`，带 `higher_moment_restrictions=[{"shock": "mp", "vs": "demand",
"comparison": "greater", "moment": "excess_kurtosis"}, ...]`。超额峰度为 Fisher 形式（峰度 − 3）。识别标签
包含"higher_moment"。
**解释：**在 T~504 的月度样本上，区间可能变宽而不是变窄（复现没有查明原因）。多冲击之间的比较可能只接受
极少的旋转（小样本失败模式）。agent 应指出这一点。
**测试什么：**AFM 2023 高阶矩约束与符号约束的组合。

### T5.10：面板 VAR（Canova-Ciccarelli 2013）
```
提示："估计一个关于货币传导的 4 国面板 VAR（英国、美国、日本、德国）。比较混合、均值组、
      贝叶斯部分混合和全局 VAR 的估计。"
```
**预期：**调用 `lib.panel` 的估计量 `fit_pooled_var`、`fit_mean_group`、`fit_partial_pooling_var`、
`fit_global_var`（还可以加上 `fit_hierarchical_panel_var`，它学习每个系数的混合强度）。报告跨国异质性
（混合与均值组的最大差异）。GVAR 通过 `PanelVARFit.cross_unit_lag_block` 和
`average_cross_unit_spillover` 展示跨单位溢出。四个估计量都使用 ML 的 Sigma_u 除数（CONVENTIONS.md
第 3 节）。
**测试什么：**面板模块（4 个估计量）、GVAR 跨单位溢出、Sigma_u 约定的一致性。

### T5.11：条件预测（Bańbura-Giannone-Lenza 2015）
```
提示："在三种情景下预测美国未来 8 个季度的 GDP：(a) 无条件，(b) 联邦基金利率保持在 5%，
      (c) 联邦基金利率保持在 0.25%（零利率下限）。用 BGL 2015 的条件预测方法。"
```
**预期：**调用 `lib.conditional_forecast`。三条预测路径 + 通过模拟平滑得到的密度区间。无条件路径与
`lib.iterated_forecast` 一致到机器精度。
**解释：**这是条件预测（所有冲击都推动路径）；识别了冲击的反事实需要单独的识别步骤。agent 必须区分。
**测试什么：**BGL 2015 条件预测、情景比较。

### T5.12：区块外生性（小型开放经济）

提示："为一个小型开放经济估计 BVAR：世界 GDP 和美国政策利率作为外国区块，加上本国 GDP、CPI 和

**预期：**识别出小型开放经济结构（经济体概况 / 提示），并通过
