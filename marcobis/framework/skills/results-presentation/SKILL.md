# 结果呈现

## 目的

把原始的计量输出转化为清楚、准确的表达。这个 skill 处理三个层面：视觉呈现（图和表）、文字解读
（叙述）和格式适配（受众是谁）。

## 设计原则

1. **清晰胜于装饰。**图要传达信息，而不是用复杂度唬人。遵循 Tufte 的原则：最大化数据墨水比，
   避免图表垃圾。
2. **准确胜于说服。**醒目地展示不确定性。绝不隐藏很宽的置信带或不利的结果。有价格之谜就展示出来。
3. **适合受众。**同一个脉冲响应，对审稿人、行长和记者意味着不同的东西。调整语言和细节，不调整
   实质。
4. **可复现。**每张图和每个表都由保存在研究日志中的脚本生成。不做手工后期处理。
5. **注意内部风格。**应用默认值之前，先查知识库中的机构格式惯例。

## 图

### 脉冲响应函数

任何 VAR 分析中最重要的图。把它画对很重要。

**布局：**
- 每个响应变量一个面板，排成网格。
- 识别了多个冲击时，每个冲击一张图（每张图包含所有响应变量的面板）。
- 横轴是期限，纵轴是响应幅度。
- 零线始终可见且醒目。

**自适应布局（必须随 `n_vars` 缩放）：**

布局参数（网格维度、面板大小、字号、面板间距、图例位置和页边距）都应根据面板个数推导，而不是
写死。6 变量的 VAR 和 12 变量的 BVAR 都应无需针对设定手工调整就能干净地渲染。参考实现在
`scripts/lib/report.py::_smart_layout`，遵循下面的规则；任何其他实现（R / Julia / Matlab）都应
遵循同样的原则。

| 面板数 n | 网格（行 × 列） | 面板目标尺寸 | 主字号 | 说明 |
|---|---|---|---|---|
| 1 | 1 × 1 | 380 × 320 px | 13 pt | 宽的单面板 |
| 2 | 1 × 2 | 340 × 280 px | 12 pt | |
| 3 | 1 × 3 | 300 × 260 px | 12 pt | |
| 4 | 2 × 2 | 300 × 260 px | 12 pt | 不要 3 + 1 |
| 5–6 | 2 × 3 | 280 × 240 px | 11 pt | |
| 7–9 | 3 × 3 | 260 × 220 px | 11 pt | |
| 10–12 | 3 × 4 | 240 × 200 px | 10 pt | |
| 13–16 | 4 × 4 | 220 × 180 px | 10 pt | |
| > 16 | ⌈n/⌈√n⌉⌉ × ⌈√n⌉ | 200 × 170 px | 9 pt | 最密 |

统一适用的规则：

- **横轴标签只放在每列最下面的面板。**避免每个面板下都出现"Quarters"，这正是下一行子图标题与
  上面标签相撞的典型原因。
- **纵轴标题只放在最左列。**默认在这里放响应变量名，子图标题保持简短或留空。当各响应有共同单位
  （例如百分比）时，给 `add_irf` / `add_standard_sections` 传 `units="Percent"`：纵轴显示单位，
  变量名移到子图标题，避免名字出现两次，也与已发表的脉冲响应图一致（即下面"标注"清单中
  "纵轴：Percent" + 面板带名称的形式）。
- **子图标题在单词边界处折成 2 行**，阈值约为 `panel_width_px / 9`。单个很长的词用省略号，
  不在词中间断开。
- **面板间距用绝对像素计算**，而不是 Plotly 默认的归一化比例。否则间距会随 `n_rows` 增大而缩小，
  导致子图标题与上面的坐标轴相撞。
- **`n_rows ≥ 3` 时图例放在右侧**（竖排），否则放在下方（横排）。图很高时，横排在下方的图例会与
  底部横轴标签相撞。
- **页边距随内容缩放**：上边距为图级标题（冲击名称）留空间；图例横排时下边距加大；图例竖排在右
  时右边距加大；左边距为纵轴标题留空间。
- **刻度标签字号比子图标题字号小 1–2 pt。**

**区间带：**
- 默认：68% 可信 / 置信区间用深色阴影，90% 用浅色阴影。
- 后验中位数（贝叶斯）或点估计（频率学派）用实线。
- 绝不只展示点估计而不带不确定性区间，除非方法不提供区间推断（`bands="none"`，例如混合面板
  拟合）。这时要清楚地把结果标为"仅点估计"（见下面"绝不伪造显著性"）。

**标注：**
- 面板标题：用平实语言的变量名（不是序列代码；中国数据用中文名，可取自 `series_info.csv`）。
- 坐标轴标签："Quarters"或"Months"（中文报告用"季度""月"），不要用"h"或"horizon"。
- 纵轴：视情况用单位、"Percent"或"Percentage points"。
- 图标题中的冲击描述："对一个标准差货币政策冲击的响应"（不是"冲击 1 的 IRF"）。

**风格默认值（期刊）：**工作区根目录的 `config.yaml` 在 `presentation.chart` 下保存它们（图和面板
尺寸、线条和区间带颜色、区间带透明度、零线颜色、线宽、衬线字体、字号、300 dpi、PDF）。把读取的
配置传给 `VARReport(config=...)`：HTML 报告使用线条和区间带颜色以及区间带透明度；matplotlib 导出
PDF 时使用其余设置，零线用虚线，不要网格，只保留下边框和左边框。中文图表需要可显示中文的字体
（如思源宋体 / 思源黑体），导出前确认字体可用。

**按受众调整：**

| 元素 | 期刊 | 政策简报 | 演示 |
|---------|---------|--------------|--------------|
| 字体 | 衬线，9–11pt | 无衬线，10–12pt | 无衬线，14–18pt |
| 颜色 | 柔和，适合打印 | 机构配色 | 高对比度 |
| 标注 | 尽量少，放在图注 | 内嵌，平实语言 | 大号，带箭头 |
| 展示的区间带 | 68% 和 90% | 只用 68%（更简单） | 只用 68%，线更粗 |
| 格式 | PDF（矢量） | PDF | PNG（用于幻灯片） |
| 图注 | 技术性 | 解释性 | 省略（口头讲解） |
| 尺寸 | 栏宽或页宽 | A4 页面 | 16:9 幻灯片 |

### 预测误差方差分解

**表格格式（期刊）：**

| 期限 | 货币政策 | 需求 | 供给 | ... |
|---------|----------------|--------|--------|-----|
| 1Q      | 85.2           | 10.1   | 4.7    | ... |
| 4Q      | 52.3           | 28.7   | 19.0   | ... |
| 8Q      | 34.1           | 38.2   | 27.7   | ... |
| 20Q     | 22.5           | 41.0   | 36.5   | ... |

数值为百分比。贝叶斯情形给出后验中位数，括号内给出 68% 可信区间。

**图形格式：**选定期限上的堆积面积图或分组柱状图。

### 历史分解

堆积柱状图或面积图，展示每个结构冲击对某个变量历史走势的贡献。基础（确定性）成分单独展示。
横轴是时间，纵轴是贡献。

有助于文字解读："2008 年产出下降主要由金融冲击（蓝色）驱动，需求冲击（橙色）的贡献较小。"

### 时变参数图（TVP-VAR）

- **不同时点的脉冲响应面板：**小多图，每个选定日期一张，纵轴刻度一致以便比较。
- **参数演变：**横轴是时间，纵轴是系数值，带后验可信区间。标注制度变化（带标签的竖线）。
- **波动率演变：**类似布局，用阴影标出已知的危机时期。

### 对比图

展示多种方法的结果时（LP 与 VAR、不同先验、不同样本）：

- 叠加在同一坐标系中，使用不同的线型和颜色。
- 图例必须清楚、无歧义。
- 一个面板上不要超过 3–4 种方法；必要时拆开。
- 标注方法一致和不一致的地方。

## 表

### 系数表

用于投稿时，遵循标准格式：

- 变量为行，方程为列。
- 系数下方括号内为标准误。
- 显著性星号：* p<0.10，** p<0.05，*** p<0.01。
  贝叶斯情形：报告系数为正 / 负的后验概率，或可信区间，而不是星号。
- 最后几行：样本量、对数似然、信息准则。

生成 LaTeX（用于投稿，按需）、Markdown（用于工作论文）或格式化的电子表格（内部使用）。

### 诊断汇总表

紧凑地报告所有诊断检验结果：

| 检验 | 统计量 | p 值 | 结论 |
|------|-----------|---------|---------|
| Ljung-Box（滞后 4） | 12.3 | 0.42 | 通过 |
| ARCH-LM | 8.7 | 0.07 | 边缘 |
| Jarque-Bera | 5.2 | 0.08 | 通过（软要求） |
| 最大特征值 | 0.94 | n/a | 稳定 |

演示中用颜色编码（绿 / 黄 / 红），投稿时不用。

## 文字解读

### 目的

agent 按受众写出平实语言的结果解读。这不是对图的机械描述，而是把统计发现与研究问题联系起来的
经济学叙述。

**报告绝不能没有文字解读。**如果没有提供解读，`VARReport.add_standard_sections(...)` 会**发出
警告**（只有图表、没有解读的报告是有缺陷的）。传 `narrative="auto"` 会通过 `lib.draft_narrative`
起草一个与经济学挂钩的骨架，依据的是脉冲响应的符号 / 量级、FEVD 份额、伴随矩阵稳定性，以及
第 5 阶段合理性检查的 `flags`（价格之谜、爆炸根……），然后由 agent **细化**成下面的文字。骨架
末尾有明确的 `[DRAFT …]` 标记，避免把未细化的解读误当成定稿。一定要细化；绝不发布原始骨架。
骨架是英文的；中文报告由 agent 改写成中文。

### 结构

**期刊论文（结果部分）：**

1. 用一句话开头给出主要发现。
2. 逐一讲解关键的脉冲响应，引用图号。
3. 指出结果与已有文献一致或不同之处。
4. 讨论不确定性：区间是否足够窄，能得出确定的结论？
5. 用经济学推理讨论任何异常（价格之谜、反直觉的符号）。
6. 概述 FEVD 结果及其对各冲击相对重要性的含义。
7. 说明稳健性：LP 是否证实了 VAR？结果对先验是否敏感？

**政策简报：**

1. 以政策含义开头："政策利率上调 100 个基点，[Y] 个季度后产出下降约 [X]%。"
2. 给出背景："这与可比经济体的估计[一致 / 偏大 / 偏小]。"
3. 平实而简短地说明局限："这些估计存在不确定性，真实效应可能在 [A] 到 [B] 之间。"
4. 避免：术语、希腊字母、提及估计方法。

**内部演示：**

1. 用要点列出关键发现，并引用图。
2. "有什么新东西"的视角：这些结果与之前的估计有何不同？
3. 用一张幻灯片概述稳健性。
4. 清楚说明对当前政策决策"意味着什么"。

### 语气和用语

- **绝不夸大确定性。**用"结果表明"，不用"结果证明"。
- **使用量级。**"政策利率提高一个百分点，产出下降约 0.3%"，而不只是"产出下降"。
- **结合文献。**"这与 Christiano、Eichenbaum 和 Evans (1999) 一致，他们发现峰值响应同样出现在
  第 6 个季度。"
- **承认局限。**每段解读都应至少包含一条相关的分析局限说明。

### 语言支持

文字解读可以用知识库或呈现请求中指定的任何语言生成。非英文产出时：

- 使用当地惯用的经济学术语（中文按国内期刊的通行译法，如"脉冲响应""方差分解""价格之谜"）。
- 遵循当地的引用惯例。
- 调整数字格式（小数逗号还是小数点、千位分隔符）。
- 如果 agent 对所请求语言中的领域术语把握不足，应当说明，并建议用户审阅措辞。

## 输出格式

### HTML 报告（主要产出）

每次模型运行都**必须**产出一个单文件 HTML 报告作为主要产出。用 `scripts/lib/report.py`
（`VARReport` 类）生成。报告把所有结果合并到一个交互式文件中。

```python
import sys
from pathlib import Path
sys.path.insert(0, str(Path(__file__).resolve().parent.parent.parent))  # 从 scripts/<tier>/<id>/ 把 scripts/ 加入路径
from lib.report import VARReport

report = VARReport(
    title="[论文] [模型] 复现",
    subtitle="[n] 变量 [模型]，[识别方式]，[数据集] [样本]",
    config=cfg,  # 传入 config.yaml 的字典，保持风格一致
)

report.add_specification(spec_dict)           # 模型细节表
report.add_irf(irf_point, ci_68_lo, ci_68_hi, # 交互式 Plotly 脉冲响应面板
               ci_90_lo, ci_90_hi,             # 按冲击分标签页
               var_names, shock_labels)
report.add_diagnostics(diag_dict, var_names)   # 按颜色编码的 p 值表
report.add_summary(summary_rows,               # 峰值响应、显著性
                   title="技术冲击摘要")       # 写明冲击名称
report.add_fevd(fevd_data, var_names, horizons,        # 热力图形式的 FEVD 表
                shock_names=shock_labels)      # 列是冲击，不是变量
report.add_robustness(baseline_irf, alt_irf,   # 叠加对比图
                      labels, var_names)
report.add_narrative(text)                      # 平实语言的解读
report.add_research_log(log_dict)              # 可折叠的 JSON 元数据

report.save(OUTPUT_DIR / "report.html")
```

**用户要求去掉警告或注意事项时：**呈现的*框架*由用户决定：横幅、"异常"标签、补救措施章节都可以
去掉。有三件事不能商量：(i) 文字解读仍然如实描述估计结果（读者能从图里看到的结果，不能绕开不写）；
(ii) 在文献会立即提出质疑的地方，保留一句中性的标准解读；(iii) 研究日志保留完整记录（标记、用户
的决定，原话照录）。应用这条边界时要说出来："设定由你决定，处置由你决定，但报告要保持真实。"

标准章节在频率和可用性方面的注意事项：

- **月度运行必须覆盖季度默认值**：调用 `add_standard_sections` 时传 `x_axis_label="Months"` 和
  月度的 `fevd_horizons`（例如 `(1, 6, 12, 24, 48)`）；默认值是 `"Quarters"` 和
  `(1, 4, 8, 20, 40)`。
- **FEVD 不一定可用。**`lib.structural_fevd` 返回单一期限的 `(n_vars, n_shocks)` 矩阵（不是脉冲
  响应形状的三维数组），并且 FEVD 要求结构冲击的方差为 1：对于按 `unit_policy` 或 `one_sd` 归一化
  的 proxy-SVAR 脉冲响应，冲击的方差尺度没有确定（`reliability` 是方差为 1 的选项）。这时
  `add_standard_sections` 会在报告中插入一条可见的"FEVD omitted"说明（不是悄悄跳过）；在文字解读
  中复述原因，而不是展示一个不完整的表。
- **绝不伪造显著性。**基于置信区间的显著性标记，要求区间上下界都有限且同号；没有区间推断的运行
  （`bands="none"`，例如只有点估计的混合面板拟合）在汇总表中显示"N/A (no inference)"，而不是星号
  或空的区间带。

报告是一个单独的 HTML 文件（约 300KB），从 CDN 加载 Plotly：分享只需一个文件，但图表第一次打开时
需要联网（离线环境的用户：把 plotly.js 打包到本地）。在中国大陆访问境外 CDN 可能较慢。

**何时添加各章节：**

- `add_specification` 和 `add_research_log`：始终（每个模型）
- `add_irf`：分析计算了识别后的脉冲响应时
- `add_diagnostics`：适用于所拟合方法的诊断；只对受支持的类 VARFit 对象用 `lib.diagnostics`，
  不适用的章节标为不适用并说明原因。表格按颜色编码：绿（p>0.10）、黄、红（p<0.05）
- `add_summary` 和 `add_fevd`：计算了 Cholesky 或结构脉冲响应时
- `add_robustness`：运行了备选设定时
- `add_narrative`：始终；由 agent 撰写解读（或细化 `narrative="auto"` 的草稿）。漏掉时
  `add_standard_sections` 会警告。

### LaTeX + PDF（可选，按需）

只有用户要求时（例如用于投稿或印刷），才与 HTML 报告一起生成。仅凭受众设置不会触发：
- 用 matplotlib 把脉冲响应图导出为 PDF（使用 config.yaml 的风格设置）。
- 表格为 booktabs 格式的 `.tex` 文件。
- 结果部分草稿为 `.tex`。

### Markdown

用于工作论文。图为 PNG，表格为 Markdown，文字解读为 Markdown 文本。

### 演示幻灯片

如果有 `pptx` skill，委托给它。每张幻灯片一张图，演讲者备注写完整的解读。

## 质量检查清单

把任何图表交给用户之前，确认：

- [ ] 所有坐标轴都标注了单位。
- [ ] 脉冲响应图中零线可见。
- [ ] 展示了不确定性区间（只有方法不提供推断时才给出仅点估计的结果，并明确标注）。
- [ ] 变量名人类可读（不是代码）。
- [ ] 图标题说明了图展示的内容。
- [ ] 配色无障碍（如未覆盖，使用色盲友好的配色）。
- [ ] 分辨率满足目标格式（印刷用 300 dpi 以上）。
- [ ] 图没有歪曲结果（例如截断纵轴夸大小的效应）。
- [ ] 数字格式符合当地惯例。

## 表达的合理性检查

正如主控检查结果的经济合理性，这个 skill 检查呈现的表达合理性：

1. **文字解读与图是否一致？**如果文字说"产出显著下降"，但 90% 区间在所有期限上都包含零，要指出来。
2. **不确定性是否得到公允的呈现？**如果区间很宽，文字解读不应夸大发现。
3. **受众是否合适？**如果用户要政策简报，但结果高度不确定、依赖模型，建议加重说明局限，或者在向
   政策制定者传达之前建议做进一步分析。
4. **是否披露了设定搜索？**按主控第 5 阶段的披露规则：文字解读必须说明最终设定之前经过了多少次
   由合理性检查引发的修改（包括"没有"），发生过修改时把第一遍结果与最终结果并列展示，并用一句话
   说明报告的区间是以这次搜索为条件的（选择后的区间，而非名义覆盖率的区间）。结果被反复迭代成形
   却不加说明的报告，不能通过这项检查。
